Install

Up and running in four steps

  1. 1

    Download the APK

    Tap the download button on your Android phone. The file is a normal Android app package.

  2. 2

    Allow the install

    Android asks whether your browser may install apps. Allow it for this one install; you can switch it off again afterwards.

  3. 3

    Choose a PIN

    Open SafeKeep and pick a six digit PIN, or skip it if your phone lock is enough for you.

  4. 4

    Make a backup

    There is no account and no recovery, so create an encrypted backup in Settings once you have notes worth keeping.

Android shows a warning for any app installed outside the Play Store. That is expected. Only install SafeKeep from this site, and check the file if you want to be sure (see below).

Verify your download

Check that the file is the real one

Every release is published with a SHA-256 checksum: a fingerprint of the exact file. If the fingerprint of your download matches, the file has not been changed on the way to you.

APK SHA-256Published with the first release
Signing certificate SHA-256Published with the first release

On a computer

Run one of these on the downloaded file and compare the result with the checksum above.

shasum -a 256 SafeKeep.apk        # macOS and Linux
certutil -hashfile SafeKeep.apk SHA256   # Windows

Updates

SafeKeep has no internet access, so it cannot update itself. To update, download the newer APK from this page and install it over the old one. Your notes stay in place. Android only accepts an update signed with the same certificate, so a fake "update" from somewhere else will be refused.
